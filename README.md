# Z'Estell-IA

Application web autonome de communication assistée.

Z'Estell-IA propose des lettres et des mots en français à partir :

- d'un lexique local orienté vers les besoins courants et les soins ;
- de fréquences de mots adaptées au français oral ;
- de règles simples de contexte grammatical ;
- d'une saisie manuelle pour compléter un mot en cours.

## Utilisation

Ouvrir `index.html` dans un navigateur récent. Aucun serveur, framework ou dépendance externe n'est nécessaire.

## Fonctionnalités

- proposition de lettres ;
- quatre mots probables ;
- validation et refus d'une proposition ;
- saisie directe d'un mot ;
- retour à l'état précédent ;
- suppression du dernier caractère ;
- réinitialisation d'une phrase ;
- interface adaptée au téléphone.

## Structure

Le prototype tient dans un seul fichier :

- `index.html` : interface, styles et logique de suggestion.
